# Cifra de Palco

App de cifras e setlists para tocar ao vivo: acordes ou graus, momentos da música (verso, refrão, ponte…), tom original e tom da cantora, diagramas, capotraste, rolagem no tempo com metrônomo e modo palco. Funciona sem internet.

**Abrir:** https://moisesquitarrinha-glitch.github.io/cifra-palco/

No iPhone: abra o link no Safari → Compartilhar → Adicionar à Tela de Início.
